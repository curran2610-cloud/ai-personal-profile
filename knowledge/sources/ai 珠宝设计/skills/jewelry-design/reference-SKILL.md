# 珠宝设计 · 项目专用 Skill

这是新建立的项目规则和知识索引。不要声称已经加载外部专业知识库，或仅凭本 Skill 就取得生产认证。

## 开始前
1. 确定当前项目目录及用户最新需求。读取当前项目的完整需求、规格、变更记录和引用参考图；对文本提取之外的图像尺寸实际看图。建立来源清单，注明读取状态。
2. 全工作区清点用于发现资料；历史案例先分类，不能将每个历史尺寸混入本项目。冲突按用户最新明确指令、当前确认规格、旧版记录的顺序处理。
3. 把信息区分为用户确认、来源标注、建模假设、模型实测、未验证。未知数据先用显式假设推进粗模；缺少工厂数据只影响生产放行，不阻止概念白模。
4. 白模/建模任务必须读取 [工作流](references/workflow.md)、[方向与证据协议](references/orientation.md) 和 [Agent 岗位指令](agents/white-model-agent.md)。检验时读取 [专业检查索引](references/knowledge.md)。

## 委派
用户要求专业 Agent 时，用可用的子 Agent 工具启动“珠宝3D白模 Agent”，传递上述文件的真实路径、当前项目路径和任务单。不能只改对话称谓就声称运行了独立 Agent。
只允许一个 Agent 写入当前模型；独立校验方只读。工具不可用时说明由主 Agent 按岗位流程执行，不伪造独立审核。
创建/评估本工作流与实际建模是不同任务。本次仅构建工作流时，不擅自开始设计或生成戒指。

## 输出及不变项
- 模型为唯一几何依据，图像仅为设计意图或参考。三视图从指定模型的正交相机输出。
- 交付仅白模：金属和宝石占位都用中性不透明白/灰，无金属反射、绿色宝石、营销光效或成品材质。
- 每个有方向的装饰实例记录稳定 ID、相对框架、正面/上方/尖端等有语义的几何锚点。方向按元素自己的基线锁定；合法的对称、环绕排列分别建基线。
- 改机位或整体转动首饰不得被误判成局部倒置。负缩放、应用变换后的几何翻转、重建拓扑必须被检查；仅对象欧拉角不够。
- 工艺修复如增厚、加圆台、圆角、减尖改变外观时，记录并进行设计复核；不得以“修复”名义静默重设计。
- 分清概念白模、几何校验通过、打印候选、指定条件下生产审核通过。面数、体素步长和封闭性不能替代尺寸精度、工艺或实物试验。

## 可执行工具
- 任务输入可复制 [任务单模板](assets/task-template.json) 到当前项目并填写；模板不包含默认珠宝款式、圈号或固定元素。
- `scripts/workflow.py inventory PROJECT --out NEW_FILE`：清点当前项目并计算文件哈希，不代表自动读懂内容。
- `scripts/workflow.py new-version PROJECT --reason TEXT`：新建下一个版本，保留历史。版本默认 draft。
- `scripts/export_scene.py`：在 Blender 中导出实际几何方向证据、单位及相机参数；用法见方向协议。
- `scripts/workflow.py compare BASELINE CURRENT --out NEW_REPORT`：检查朝向、镜像、缺失元素、拓扑与证据变化。只能验证所登记方向，不能替代装饰形态和工艺审核。
- `scripts/test_workflow.py`：运行方向防错及版本隔离测试。

## 交付
模型、白模视图、参数/假设、实际相机参数、方向快照、尺寸与工艺报告、来源清单、版本清单及文件哈希应对应同一发布版本。报告明确“通过/不通过/未验证/不适用”和证据来源。已知失败项不可被藏在附件里再于最终答复宣称可生产。
