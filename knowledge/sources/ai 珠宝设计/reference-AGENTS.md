# 项目协作规则

- 不输出非必要说明；优先具体行动。风险、阻塞、重要发现再简短说明。
- 珠宝设计、白模、迭代及出图任务，先完整读取 `skills/jewelry-design/SKILL.md`，再按相关路径读取引用文件。
- 此 Skill 是本项目新建的工作规则及知识索引，不是已经存在的认证专业知识库。
- 当前交付默认仅为中性白/灰白模。金色、祖母绿等材质意向保留在规格中，不自动生成成品材质效果图。
- 装饰方向约束适用于任意元素：防止未经授权的上下颠倒、镜像、翻面和相对朝向漂移，不意味着所有元素必须朝同一全局方向。
- 不把旧案例的尺寸、圈号、钻数、工艺假设当成新项目要求。`studies/` 和 `concepts/` 为历史资料。
- 历史版本只读；新迭代写入新版本目录。新工作流不追认旧文件已通过验收。
