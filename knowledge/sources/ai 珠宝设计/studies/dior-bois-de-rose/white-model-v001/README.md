# 白模 v001

用途：用 Dior Bois de Rose 单张照片验证参考图→可调白模→同模型正交三视图的流程。是近似练习模型，不是原款测量复刻。

## 文件
- white-model-v001.blend：实际 Blender 模型，连续封闭网格，4 台已设置相机。
- review-sheet.png：三视图及斜视检查图。
- top.png / front.png / right.png：同一模型直接渲染的正交三视图。
- hero.png：斜视造型检查图。
- parameters.json：重建参数；修改后运行 build.py 可重新建模出图。
- measurements.json：实际网格测量及检查结果。
- build.py：Blender 建模与渲染脚本。

## 尺寸假设
内径 16.5 mm；径向厚度 1.6 mm；基础轴向宽度 2.0 mm。
采用 3 处向上节点、2 处向下短节点，位置/宽度/高度均为可修改的推测。
当前参数是本次试验起点，不宣称通用行业标准。
实际外径约 19.70 mm，包含波动及节点的总轴向高度约 4.96 mm。

## 使用方式
直接打开 blend 查看和编辑网格，切换 CAM_TOP / CAM_FRONT / CAM_RIGHT 查看正交相机。
参数源以 parameters.json 为准，改动后用 Blender 后台运行 build.py。
模型上的自定义属性是本轮参数记录，不是实时驱动器。
手动编辑模型前另存新版本；重跑脚本会重建并覆盖本目录产物，因此后续迭代应复制整个版本目录再修改参数。
本轮内嵌参数文本与外部参数相同；后续由脚本重建时刷新。

## 验证
Blender 5.2.2 后台成功建模、保存并渲染 4 个角度。
40960 顶点、40960 面；非流形边 0；实测内径约 16.5 mm。
顶、正、右相机分别处于 +Z、-Y、+X，均朝原点，正交尺度均为 25 mm。
斜视为辅助检查图，不作为三视图之一。
未检查自相交、最小局部壁厚、舒适度或制造适用性。

## 后续优化重点
先评审波浪起伏、节点大小与疏密、侧面宽窄，再决定是否需要调整戒围。
当前模型的内径保持圆形包络；原照片的截面、隐蔽结构并未得到复原验证。
白模不包含材质颜色、刻字或宝石。
