# 竖屏口播剪辑

## 从参考提取剪法

先覆盖全片，找开场、举证、章节切换和结尾的重复版式。对最有代表性的动效在入场、运动中、停稳和退出各取帧，记录素材占画面比例、清晰区、停留时长和关键词的语音落点。镜头变化分开写实测、观察和推断。亮闪、字幕换字、推拉都可能触发场景检测，确认相邻帧后再决定是否算切点。

按本片口播做一张简短场景表。每段指定主视觉、配图首次需要读清的词、允许保留的辅助元素及返回人物的时机。成片只能支持对可见效果的判断，制作软件、字体名称和分轨参数只有明确来源时才写。

## 从开场到结尾

- 按原声标记设问、让步、举证、解释、转折和结论。画面点跟语义和语气走，允许素材跨过自然停顿。保留气口、原声和镜头里的表情变化，除非用户另有剪词要求。
- 开场用原话或它能支撑的一个问题。让第一张真实素材随关键字进场，再在口播提到具体消息时逐张给出处或报告。弹入、扫光、贴纸用于强调关键拍，重点信息出现后留稳。
- 普通解释保留全屏人物。短文字、关键词或两项关系图放在脸以外的留白处。若当帧有手势或举物，重新定位文字并保留动作。
- 观众需要读证据时，让原图做主画面，把人物蒙版放在避开正文和平台控件的空角。先给整图和出处，沿单一阅读方向推近，再把划线或框选绑定到原文位置；字号、标注和字幕之间只留一个主焦点。核对报告原字和素材语境，示例及局限应如实标明。
- 逐项对比时每拍只突出一个区别，图片整张等比显示，标题放到图片外。静置时间从阅读量和口播句段推算，允许跨句保持，不为每句加动画。
- 结尾用一句话回答开场问题。允许声音多走一拍，结论在画面里留够阅读时间。字幕承接原话，动效文字负责结构。
- 人物与图证双向切换时先采样过渡中间帧。优先让同一人物框连续缩放或位移，必要时短暂遮盖切点。避免两个主体、两套字幕、过渡中的底层素材同时露出。
- BGM 保持稳定垫底，让配乐在开头和结尾自然进出。已有自动压低时检查音量包络是否叠加。视觉动效选少量有意义的音效点。

## 在阿杜导演 MEP 中应用

按工程 README 和当前回执操作。提交前读最新 project.json；对已有用户编辑做最小修改；使用当前协作口令。保护专业模板自己的页面和数据，以工程独立页面和轨道实现补充动效。优先使用现有字幕、素材和时间点；自动识别、自动编排及付费生成按当前任务的授权和工具回执处理。

预览开场、每个重要转场的前后及中间、每张证据图和结尾。验证画面无重叠、报告标注可读、人物和字幕不被遮挡、原声音轨连续以及配乐没有重复压低。说明实际做到的验证范围和出口状态。

对标「小Lin竖着说」时，读 [六条本地竖屏样片拆解](references/lin-vertical-samples.md)；应用时以本片的口播和素材为准。成品混音的响度范围只能核对整体动态，不能当作 BGM 或效果音分轨参数。

需要逐项比对报告运镜、环绕分层、开头信息密度、字幕和色调时，读 [小Lin竖屏剪辑全维度拆解](references/lin-editing-grammar.md)。

将目标和工具分工交给另一个剪辑 Agent 时，使用 [剪辑 Agent 制作目标](references/agent-editing-brief.md)。
