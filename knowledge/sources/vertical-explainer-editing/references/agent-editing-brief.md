# 给剪辑 Agent 的制作目标

做一条 9:16、以口播为主的竖屏视频。参考头部知识口播的叙事和视听节奏。用人物表达判断，用实拍解释动作和做工，用报告或图表提供可读证据。主画面在每次交接中引导观众看清一个问题。

## 输入与镜头决策

读取完整原声和逐字时间码、现有素材库、参考成片、用户平台安全区约束和可编辑工程。按全片看参考，重点抽查开场、正文证据段、人物控场段和结尾，并对具体转场做密帧复查。字体和软件来源可从原工程或制作说明确认；只有成片时记录可见处理和像素测量。

先出全片镜头表，再做动效。每一行包含时间、完整语义、主画面、切镜理由、观众要读的词或看到的动作、素材来源、读屏停留、出入方向和关键音效落点。

- 抛题和判断以人物为主。真实细节、证据和图表需要看清时，可接管全屏，口播继续走。
- 图片有原标注时保留整张。密集报告先露出处与整页，再按前镜动作或阅读方向推到原词。高亮绑定报告坐标，图和标记同步变角。
- 需要记住的结论用少量独立花字。普通字幕覆盖全口播，按完整语义断句，控制在一到两行，用统一字号。长句优先改换行和分段。核对专有名词和用户指定写法。
- 混音从人声出发。常规音效略低于人声，必要的引导瞬态可接近人声，底乐稳定压在最下，避免泵动。用段落预览检查落点、音量和峰值。

## 执行与验证

阿杜导演台保留可编辑主时间线、口播、字幕、配乐和资料素材。可编辑的简单标题、图卡、节奏动效及平面推近留在工程代码场景中。

需要真正的 AE 合成时，在有可用 After Effects 的设备上用经过验证的合成模板或 JSX 创建分层图形、跟踪、三维材质等组件，再用 aerender 批量渲染。先验证 1–2 秒短样片的画幅、帧率、是否需要 Alpha、透明边缘和导入表现，确认后在主时间线接回。交付区分已渲染组件与可编辑源。

逐段复核人物切出切回、素材首尾、语义断句、手机字号、源图完整性、声画同步和峰值。现有用户修改优先，每次提交前读取当前工程版本。交付说明实际使用的工具、已验证的效果和仍需确认的素材。
