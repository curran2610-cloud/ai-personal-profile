## 1. K金基础回顾（简要）

K金（Karat Gold）是黄金与其他金属（银、铜、锌、镍等）的合金，用于提升硬度与改变颜色。

- **24K**：≥99.9% 纯金，理论100%为24K
- **22K**：91.6%
- **18K**：75% 黄金（常见首饰用）
- **14K**：58.5%
- **10K**：41.7%（美国最低"黄金"标准）
- **9K**：37.5%（英国/澳洲常见）

**常见K金印记对照表：**

| 黄金含量 | 通用印记 | 欧式/美式印记 | 中文常见印记 |
| :--- | :--- | :--- | :--- |
| 99.9% | AU999 / G999 | 999 | 千足金 |
| 75% | AU750 / G750 | 18K / 750 | 18K金 |
| 58.5% | AU585 / G585 | 14K / 585 | 14K金 |
| 41.7% | AU417 / G417 | 10K / 417 | 10K金 |

## 2. K金真伪鉴别方法

| 方法 | 原理 | 操作方式 | 真品反应 | 仿品反应 | 可靠性 | 是否破坏性 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **看钢印法** | 正规金饰必须有纯度印记 | 用30倍放大镜观察内侧/扣头 | 字迹清晰、凹陷深刻、符合AU/G标准 | 字迹模糊、浮印、无标准印记 | ⭐⭐⭐⭐ | 否 |
| **磁铁法** | 纯金及标准K金无磁性 | 用强磁铁（钕磁铁）靠近 | 无吸附（18K/14K通常无磁） | 有吸附（铁/镍合金镀金） | ⭐⭐ | 否 |
| **密度法** | 黄金密度大（19.32），合金密度可算 | 排水法测体积，电子秤称重计算 | 24K≈19.3；18K≈15.5-16.5；14K≈13.5-14.5 | 数值偏差大（如钨金除外） | ⭐⭐⭐⭐ | 否 |
| **试金石法** | 金在石上留痕，滴加硝酸看反应 | 在试金石划痕，滴硝酸 | 条纹不变色 | 条纹消失或变绿 | ⭐⭐⭐⭐ | 轻微 |
| **火烧法** | 真金抗氧化，合金受热氧化 | 用喷枪烧红后冷却 | 24K不变色；18K可能微变但抛光恢复 | 变黑、发蓝、起皮（铜/合金） | ⭐⭐⭐⭐⭐ | 是 |
| **酸测法** | 硝酸/王水与金属反应 | 滴硝酸在不起眼处 | 不变色或微反应 | 冒泡、变绿（铜）、溶解 | ⭐⭐⭐⭐ | 是 |
| **光谱仪法** | XRF荧光光谱分析元素成分 | 仪器贴紧表面扫描 | 显示AU及合金比例精准 | 显示无金或含量极低 | ⭐⭐⭐⭐⭐ | 否 |
| **陶瓷划痕法** | 硬度与色彩附着 | 在陶瓷底板上划一下 | 留下金黄色条痕 | 留下黑色条痕 | ⭐⭐ | 轻微 |
| **牙齿咬痕法** | 纯金极软（莫氏2.5） | 用牙咬（不推荐） | 24K留牙印 | 无痕迹（合金/钨） | ⭐ | 是 |

## 3. K金常见造假手段与识别

1. **镀金 (Gold Plated)**：
   - 表面仅为0.05-0.5微米金层。
   - **识别**：磨损处（扣头、棱角）露出白色/铜色内芯。
2. **包金 (Gold Filled)**：
   - 金层较厚（约5%重量），标有"GF"。
   - **识别**：不易掉色，但断面可见分层，密度低于同体积K金。
3. **沙金/越南沙金**：
   - 含金量极低（<5%），实为铜合金。
   - **识别**：颜色偏白、偏淡黄；密度低（约8-10）；酸测剧烈反应。
4. **钨金造假（高端骗局）**：
   - 钨密度19.25与金19.32极近，空心填钨。
   - **识别**：XRF测表面为金，需钻洞或切段测内部。
5. **铱金掺假**：
   - 铱密度22.56，熔点高，掺入增重。
   - **识别**：XRF可测出非金元素，熔融后表面有白斑。

## 4. 银的真伪鉴别方法

| 方法 | 原理 | 操作方式 | 真品反应 | 仿品反应 | 可靠性 | 是否破坏性 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **看钢印法** | 925银必有S925或Sterling | 观察扣头/内圈 | 清晰"S925"或"925" | 无印记、刻字模糊、标"GP" | ⭐⭐⭐⭐ | 否 |
| **磁铁法** | 银无磁性（白铜也无磁） | 用磁铁测试 | 不吸附 | 吸附（钢/铁） | ⭐⭐ | 否 |
| **密度法** | 银密度10.49 g/cm³ | 排水法测密度 | 数值接近10.49 | 白铜8.8；锌合金6.7-7.0 | ⭐⭐⭐⭐ | 否 |
| **声音法** | 银传导音频特性 | 丢在玻璃台面上 | 清脆悠长、"叮——" | 沉闷短促、"啪" | ⭐⭐⭐ | 否 |
| **化学法** | 银试剂（硝酸基）反应 | 滴一滴在隐蔽处 | 乳白色/奶油色沉淀 | 绿色/蓝色（白铜） | ⭐⭐⭐⭐ | 轻微 |
| **火烧法** | 银抗氧化，合金氧化 | 烧热后冷却 | 依然是雪白亮银 | 发黑、变灰（铜/镍） | ⭐⭐⭐⭐⭐ | 是 |
| **导热法** | 银导热极快（仅次于钻石） | 放在冰块上 | 冰块迅速融化 | 融化慢 | ⭐⭐⭐ | 否 |
| **漂白水法** | 银遇硫/氯变黑 | 滴84漂白水 | 迅速变黑（硫化银） | 不变色或变其他色 | ⭐⭐⭐ | 轻微 |
| **白醋法** | 酸与活泼金属反应 | 浸泡或滴醋 | 无明显反应 | 冒泡、变色（锌/铜） | ⭐⭐⭐ | 轻微 |

## 5. 银常见造假手段与识别

1. **白铜/镍银 (German Silver)**：
   - 铜+镍+锌，无银成分。
   - **识别**：银试剂变绿；密度偏低（8.8）；戴久不过敏但无银光泽。
2. **镀银 (Silver Plated)**：
   - 铜或白铜表面电镀。
   - **识别**：磨损处露黄色/红色；截面分层；火烧后镀层起皮。
3. **锌合金镀银**：
   - 地摊货常见，极不耐用。
   - **识别**：重量极轻；硬度低，指甲能划出印；容易氧化发绿。
4. **不锈钢仿银**：
   - 316L钢，用于低成本首饰。
   - **识别**：硬度极高，无法用金属刻划；磁铁有时微吸附；密度7.8。

## 6. 克罗心 (Chrome Hearts) 专属鉴定要点

### 6.1 银饰鉴定核心

- **字体工艺**：正品"Chrome Hearts"刻印有手工刀锋的立体感，深峻清晰；激光刻印的仿品字迹边缘发虚、平浅。
- **年份码与©符号**：早期克罗心使用特定的©字体，且带有日期代码（如97、02等），仿品常忽略或印错字体细节。
- **系列码与流水号**：正品内圈会有精细的系列编码和独立流水号，字体间距均匀；仿品常使用通用号或模糊处理。
- **内圈抛光**：正品内圈为镜面抛光或极细腻的拉丝工艺；仿品内圈常有铸造砂眼或粗糙打磨痕迹。
- **焊接点**：十字架吊坠的银环焊接点极小且牢固，过渡自然；仿品焊接点大、有焊疤或缝隙。
- **重量感**：克罗心以"重银"著称，同款仿品因偷工减料（壁厚减薄）通常比正品轻15%-20%。

### 6.2 K金饰品鉴定（18K）

- **印记位置**：克罗心18K金印记通常在扣头内侧或饰品隐蔽处，字体具有品牌特定风格。
- **重量差异**：18K金密度（约15.5-16.5）是925银（10.49）的1.5倍。同款式的18K版本会比银版重很多。
- **颜色特征**：克罗心18K金多采用"特浓"工艺，颜色偏复古淡黄，不同于国内金店的亮黄。

## 8. 鉴别流程图

### K金鉴别决策树
1.  **看钢印**：无标准印记（AU750/999） -> 存疑/假。
2.  **磁铁**：强吸附 -> 假（非金合金）。
3.  **称重密度**：计算密度，与理论值偏差>5% -> 假（如钨金需特殊手段）。
4.  **试剂/火烧**：酸测变色或火烧变黑 -> 假。
5.  **XRF**：最终仲裁。

### 银鉴别决策树
1.  **看钢印**：无S925/Sterling -> 假/次品。
2.  **磁铁**：吸附 -> 假（钢/铁）。
3.  **声音/导热**：声音沉闷、导热慢 -> 合金。
4.  **密度**：测排水密度，远低于10.49 -> 锌合金/白铜。
5.  **试剂/火烧**：银试剂变绿或火烧发黑 -> 假。

## 9. 电商/二手市场常见骗局与避险

- **骗局 1：越南沙金当18K卖**
  - 特征：价格极低（<100元/克），颜色不正。
  - 避险：要求提供密度数据或XRF报告。
- **骗局 2：镀金/镀银当真品**
  - 特征：边角磨损图打码，或价格远低于行情。
  - 避险：索要接口/扣头微距图。
- **骗局 3：银镀白金当铂金卖**
  - 特征：只有"S925"印记，却按铂金价卖。
  - 避险：认准"PT950/PT990"印记。

**避险建议**：
1. 要求自然光下的微距实拍图（特别是刻印和磨损处）。
2. 走第三方鉴定平台（如得物、中检）。
3. 索要原始购买凭证（小票、身份卡）。
4. **价格锚点**：18K金售价若低于【当日金价 × 75% × 克重】的1.5倍（含工费），需高度警惕。

## 10. 快查速记卡

- **24K金**：颜色赤黄、极软、火烧不变色、密度19.32。
- **18K金**：印记AU750/G750、密度15.5-16.5、酸测不变色。
- **925银**：印记S925、密度10.49、氧化变黑正常、声音清脆。
- **白铜假银**：无银印记、密度8.5-8.9、银试剂变绿、烧后发黑。
- **沙金假金**：颜色偏白淡、密度偏低、酸测变绿、无标准K金印记。
