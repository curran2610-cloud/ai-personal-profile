## 1. 基础概念

### 1.1 K金的定义
*   **K (Karat)**：黄金纯度的计量单位。
*   **理论纯度**：理论上，纯金为 24K。1K 的含金量约为 1/24（约 4.1667%）。
*   **实际定义**：在珠宝首饰领域，K金是指黄金与其他金属（如银、铜、钯、镍等）熔合而成的**合金**。加入其他金属是为了增加硬度、改变颜色并降低造价。

### 1.2 常见K金含金量对照表

| :--- | :--- | :--- | :--- |
| **24K** | ≥ 99.9% | Au999 / 千足金 | 质地太软，极少用于镶嵌，多用于金条、摆件 |
| **22K** | 91.6% | Au916 | 印度及中东市场极流行，硬度略高于纯金 |

### 1.3 国标与足金概念 (GB 11887)
*   **足金**：根据国家最新标准（GB 11887-2012），黄金含量达到 99.0% 以上的首饰统称为"足金"。取消了过去的"千足金（99.9%）"和"万足金（99.99%）"的说法，统一为"足金"。
*   **K金 vs 足金**：K金强调硬度与设计感；足金强调保值与纯度。

### 1.4 核心概念区别：纯金、合金、镀金、包金
| 名称 | 英文 | 定义 | 克罗心应用情况 |
| :--- | :--- | :--- | :--- |
| **纯金/足金** | Pure Gold | 含金量极高（>99%），质地软，易变形。 | 极少使用 |
| **K金 (合金)** | K-Gold (Alloy) | 黄金+其他金属，硬度高，适合镶嵌。 | **奢侈品主流** |
| **镀金** | Gold Plated | 表面电镀一层极薄的金（通常<0.05微米），基底多为银或铜。 | 快时尚珠宝常用，克罗心官方极少用 |
| **包金** | Gold Filled | 机械压合，金层较厚（>5%总重），比镀金耐用。 | 少见 |
| **鎏金** | Gold Wash | 传统工艺，将金汞齐涂于器物表面后加热蒸发汞。 | 古法工艺，现代首饰少见 |

## 3. 彩色 K 金（彩金）成分解析

K金的颜色由与其熔合的金属种类决定。

### 3.1 常见颜色与配方
*   **黄色 K 金**：黄金 + 银 + 铜（保持金黄本色）。
*   **白色 K 金**：黄金 + 钯/镍/银（表面需镀铑 Rhodium 才显亮白）。
*   **玫瑰金 (Rose Gold)**：黄金 + 高比例铜（铜越多越红）。
    *   *18K 玫瑰金标准配方参考*：75% 黄金 + 22.25% 铜 + 2.75% 银。
*   **绿色 K 金**：黄金 + 高比例银（或镉，因环保现已少用）。
*   **黑色 K 金**：黄金 + 高比例钴/铁（或表面做黑色镀层/氧化）。

### 3.2 克罗心偏好的金属
*   克罗心 (Chrome Hearts) 以 **925 银** 为核心，但在高级珠宝线或特定系列中，也会使用 **18K 黄金** 或 **18K 白金** 来搭配钻石，以体现奢华感。

## 4. K 金与铂金 (Platinum) 的核心区别

这是销售中最常见的混淆点。消费者常把"白金"等同于"铂金"。

| 对比维度 | 18K 白金 (White Gold) | 铂金 (Platinum, 如 Pt950) |
| :--- | :--- | :--- |
| **本质** | **黄金合金**（75%黄金+25%其他白色金属） | **天然白色贵金属** |
| **印记** | Au750 / G18K | Pt950 / Pt990 |
| **颜色来源** | 本身呈微黄色，需**电镀铑 (Rhodium)** 才亮白 | 天然纯白，不会褪色 |
| **硬度** | 较高，适合镶嵌大克拉钻石 | 相对较软，时间久了会有"磨花"质感（压克力感） |
| **重量** | 较轻（密度约 15.5 g/cm³） | **极重**（密度约 21.4 g/cm³），有沉甸甸的压手感 |
| **过敏性** | 少部分人可能对镍（漂白剂）过敏 | 纯度极高，几乎不导致过敏 |
| **价格** | 金价 + 工费（通常低于同重铂金） | 通常高于黄金（按克重计价时） |

> **销售重点**：18K白金是"看起来像铂金"的黄金，白亮是靠电镀；铂金是"永远纯白"的稀有金属。

## 5. K 金首饰工艺与保养

### 5.1 常见工艺
1.  **铸造**：失蜡浇铸（最常用）、3D硬金（电铸）、CNC电脑车花（克罗心十字花常用）。
2.  **表面处理**：抛光（镜面）、喷砂（磨砂）、拉丝（发丝纹）、做旧（克罗心银饰常见，K金少见）。
3.  **镶嵌**：爪镶（最显钻石）、包镶（最牢固）、微镶（铺钻）、槽镶（婚戒常见）。

### 5.2 日常保养指南
*   **化学品**：洗澡、游泳、喷香水、涂乳液前请摘下。化学品会腐蚀K金表面的镀层（尤其是白K金的电镀层）。
*   **物理碰撞**：虽然K金硬度高，但剧烈碰撞仍可能导致变形或钻石松动。
*   **清洁**：用软毛刷蘸取稀释的中性洗洁精轻刷，清水冲净，软布擦干。
*   **电镀翻新**：18K白金佩戴1-2年后可能会露出微黄色底色，需进行"重新电镀铑"维护，可恢复亮白。

## 8. 销售话术 / 客户答疑 (实战)

### Q1: 18K金会不会褪色/掉色？
*   **答**：18K金本身是黄金，不会"掉色"。但18K白金表面有一层镀铑层，长期佩戴摩擦后，这层白色镀层可能会变薄，露出里面微黄的底色。这属于正常磨损，并非假货。拿回店里重新电镀一下就可以恢复如新。玫瑰金和黄金由于是本体颜色，不存在掉色问题。

### Q2: 白金和铂金哪个好？
*   **答**：这要看您的需求。如果您追求**硬度高、镶嵌牢固、性价比高**，选18K白金；如果您追求**天然纯白、重量感强、不过敏且永不褪色**，选铂金（Pt950）。两者都是顶级珠宝的常用材质。

### Q3: K金和足金哪个保值？
*   **答**：如果单纯看**回收变现**，足金（999金）按克重回收，折价少，更保值。但K金首饰（尤其是奢侈品牌）卖的是**设计、工艺和品牌**，买的时候溢价高，回收时主要看金料重量。如果您是为了佩戴漂亮、彰显品味，K金的设计感和硬度优势是足金无法比拟的。

### Q4: 为什么克罗心 (Chrome Hearts) 多用925银而不是K金？
*   **答**：克罗心的灵魂在于其独特的**哥特式美学**和**氧化做旧的质感**。925银质地偏软，更容易雕刻出克罗心那种复杂的花纹，且银的暗黑光泽更符合品牌调性。K金虽然贵，但颜色太艳丽（黄/白），无法呈现克罗心那种"高街、叛逆"的独特风格。当然，他们也有K金配钻的高端线，但银饰才是经典。

### Q5: 戴K金首饰过敏怎么办？
*   **答**：过敏通常是对合金中的镍(Nickel)过敏。如果您易过敏，建议选择**18K黄金**或**18K玫瑰金**（通常不含镍），或者选择**铂金**。如果是18K白金，确保表面的镀铑层完好，可以隔离金属与皮肤。

## 9. 常见误区 / 谣言澄清

1.  **误区："18K金掉色 = 假货"**
    *   **正解**：18K白金的电镀层磨损属于正常物理现象，不是假货。
2.  **误区："K金越纯越值钱"**
    *   **正解**：原料层面是的，但在珠宝层面，设计、品牌（如卡地亚的18K金）的价值远超黄金原料本身。
3.  **误区："K金可以吃/可以入药"**
    *   **正解**：现代K金含有铜、镍等金属，不可食用。古代"吞金"致死是因为物理损伤或重金属中毒，绝非保健。
4.  **误区："玫瑰金是染色的"**
    *   **正解**：玫瑰金的红色是铜与金形成的天然合金颜色，不是染色，不会洗掉。
