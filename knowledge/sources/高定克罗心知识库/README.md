# 克罗心产品内容编导实战手册｜Codex 交接包

## 项目定位
本项目不是普通“短视频文案库”，而是一套用于新人编导、新人文案、新人剪辑、销售转内容人员的内部训练体系。

核心目标：把高定做货克罗心产品的真实产品价值、工艺知识、用户问题、画面素材和爆款传播方法，沉淀成可复制、可训练、可迭代的《产品内容编导实战手册》。

## 写作总原则
1. 实战、通俗、内部培训感，不学院派。
2. 所有内容都要服务新人“干中学”。
3. 不是只告诉新人“是什么”，而是告诉新人“为什么这样讲、怎么用到视频里”。
4. 每个产品知识点都要能对应：用户问题、传播公式、情绪入口、画面证据、风险边界、可转化选题。
5. 后端创造产品价值，前端表达产品价值。
6. 视频不是为了讲完知识，而是为了驱动用户进入下一秒。
7. 新人先复刻，再理解，最后创新。
