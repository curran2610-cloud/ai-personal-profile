# 06 文案结构

## 核心问题：一条短视频到底应该怎么组织？
公式、留人、情绪、评论、画面，最后都要落到一件事上：一条视频到底怎么写。

文案结构的作用，是把信息排成一条清晰的观看路径。

## 一、什么是文案结构
文案结构是一条视频的信息排列顺序。它不是简单的开头、中间、结尾，而是每一句话在整条视频里承担什么任务。

第一句负责留人。第二句负责放大问题。第三句负责解释原因。第四句负责给证据。第五句负责带出产品价值。最后一句负责引导评论。

## 二、基础文案结构：六步法
钩子 → 放大问题 → 解释原因 → 给出证据 → 回到产品价值 → 引导评论

### 第一步：钩子
让用户停下来。

### 第二步：放大问题
让用户意识到这不是小问题，和他有关。

### 第三步：解释原因
开始进入知识，但解释要围绕开头问题。

### 第四步：给出证据
产品细节、工艺过程、对比图、评论截图、佩戴效果都可以做证据。

### 第五步：回到产品价值
告诉用户为什么这个细节、工艺、差异会影响价格、佩戴、收藏、真假、玩家认可。

### 第六步：引导评论
不要把话说死，给用户一个接话的位置。

## 三、常用结构类型
- 行业变化型结构
- 价格冲突型结构
- 真假焦虑型结构
- 身份认同型结构
- 工艺震撼型结构
- 故事代入型结构

## 四、每句话只能完成一个任务
短视频文案要短，但不能乱短。短不是把所有信息压成一句，而是把每个信息点拆清楚。

一句话负责反差，一句话负责解释，一句话负责知识，一句话负责观点。

## 五、本节总结
短视频文案不是说明书，而是观看路径。

每一句话都必须有任务。

结构不是限制创作，而是让内容稳定输出。

基础结构：钩子 → 放大问题 → 解释原因 → 给出证据 → 回到产品价值 → 引导评论。
