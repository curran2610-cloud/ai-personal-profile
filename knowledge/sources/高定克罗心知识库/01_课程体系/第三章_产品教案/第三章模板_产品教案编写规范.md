# 第三章产品教案模板

用于后续围绕具体产品写 10 篇以上产品教案。

## 教案编号
例如：Baby Fat - 001

## 对应产品
Baby Fat / 十字架 / 戒指 / 手链 / 牛仔裤等

## 使用公式
从第一章选择：行业变化、身份认同、价格冲突、真假焦虑、工艺震撼、故事代入等。

## 主要情绪
危机感 / 好奇心 / 身份感 / 风险感 / 反认知 / 占便宜心理 / 代入感

## 视频目的
涨粉 / 评论 / 建立信任 / 种草 / 成交 / 避坑 / 私域承接

## 对应产品知识点
来自第二章的知识条目。

## 核心观点
这条视频要让用户记住的一句话。

## 完整文案
按短视频口播写出完整正文。

## 逐句批注
每一句都标：
- 话里逻辑：这句话表面在说什么。
- 话外逻辑：真正想引导用户怎么想。
- 传播任务：留人 / 放大问题 / 解释原因 / 给证据 / 回到产品价值 / 引导评论。
- 对应知识点：来自第二章哪个产品知识。
- 对应画面：放什么画面，为什么。
- 调动情绪：好奇 / 风险 / 身份 / 反认知等。

## 画面拆解
按秒数或句子拆：
- 画面内容
- 画面任务
- 素材要求

## 评论口
不能只写“你怎么看”，必须具体、可回答、有分歧。

## 可替换版本
这个结构如何换成其他产品。

## 风险边界
哪些表达需要弱化，哪些结论不能绝对化，哪些地方必须用证据。
