# 口播脚本模板库

## 模板一：三点避坑

适用：新人科普、产品细节、私域引流。

结构：

1. 开头提出痛点：很多人买这类产品，只看外观，所以容易踩坑。
2. 给出判断标准：真正要看的是三点。
3. 分点讲解：材质、工艺、细节。
4. 收尾承接：不懂可以把你的预算和想要的款式发来，我帮你判断适不适合。

示例骨架：

```text
很多人看这类产品，第一眼只看像不像。
但真正决定质感的，通常是这三点。
第一，看材质。……
第二，看工艺。……
第三，看细节。……
如果你是第一次接触，别急着下单，先把预算、使用场景和喜欢的款式想清楚。
```

## 模板二：成本拆解

适用：牛仔裤、金饰、银饰。

结构：

1. 用价格制造反差。
2. 拆成 3 到 4 个成本模块。
3. 解释为什么差价大。
4. 引导用户理性判断。

```text
一条看起来只是改造过的牛仔裤，为什么价格能差这么多？
先别急着说贵，拆开看就清楚了。
第一是底板……
第二是拼皮……
第三是五金……
最后还有人工和细节调整。
所以判断值不值，不是只看外观，而是看每一步有没有做到位。
```

## 模板三：圈层认知

适用：高客单客户、老玩家、留学生、穿搭人群。

结构：

1. 提出普通人看法。
2. 转到老玩家/高客单客户视角。
3. 解释消费逻辑。
4. 落到产品使用场景。

```text
普通人看这类产品，第一反应可能是贵。
但老玩家看的不是单价，而是这个东西适不适合自己的场景。
收藏款有收藏款的逻辑，日常佩戴有日常佩戴的逻辑。
真正会买的人，反而会把这两件事分开。
```

适用：建立信任、展示产品细节。

结构：

1. 客户需求
2. 产品方案
3. 细节处理
4. 成品效果
5. 私域承接

```text
所以我们在方案上重点处理了三件事。
第一……
第二……
第三……
成品出来后，最值得看的就是这个细节。
```

## 模板五：热点承接产品

适用：明星同款、品牌联名、娱乐热点。

结构：

1. 用热点开场。
2. 不停留在八卦，转到穿搭或产品逻辑。
3. 给普通用户建议。

```text
最近这个同款又被带火了。
但我觉得普通人不要只看谁戴了，而是要看它适不适合自己。
这类款式的优势是……
但不适合的人也很明显……
如果你预算有限，建议先从……
```
