# 私域承接话术

## 私域目标

私域不是简单报价，而是完成客户分层。

要判断：

- 预算
- 品类
- 使用场景
- 是否懂货
- 是否老玩家
- 是否只问低价
- 是否有明确成交时间

## 开场话术

```text
你主要想看饰品、牛仔裤还是箱包？
我先按你的预算和使用场景，给你筛几个更合适的方向。
```

## 预算确认

```text
你这次大概想控制在什么预算？
我好判断是给你看入门款、日常佩戴款，还是细节要求更高的高定款。
```

## 场景确认

```text
你是自己日常戴/穿，还是送人，或者是想搭某个固定风格？
不同场景推荐会不一样。
```

## 低价客户筛选

```text
如果只是想找最低价，那这类产品可能不太适合。
我们这边主要看材质、细节和上手质感，适合对品质有要求的客户。
```

## 高意向客户推进

```text
你这个需求比较明确。
我建议先定三个点：预算、尺码/尺寸、想要的风格。
确认后我给你发对应方案和细节图。
```

## 风险边界说明

```text
我们会把材质、工艺和细节讲清楚，适合自戴和穿搭。
不建议拿去做二级流通或不符合产品定位的用途。
```
