# 自媒体前端运营知识库

这个文件夹用于长期沉淀自媒体前端运营方法。

核心目标：

- 把组长经验沉淀成 SOP
- 提高新人产出下限
- 提高有效进粉
- 提高高消费客户占比
- 降低组长逐条指导成本
- 支持管理汇报和团队复盘

## 文件说明

- `00_长期协作设定.md`：Codex 长期协作角色和工作边界
- `01_业务背景与团队现状.md`：业务链路、团队现状、当前问题
- `02_产品细节表达词库.md`：金银饰、牛仔裤、箱包等产品语言
- `03_短视频选题库.md`：选题分类、选题模板、评分标准
- `04_封面标题SOP.md`：封面和标题制作标准
- `05_口播脚本模板库.md`：可直接复用的口播结构
- `06_平台内容策略.md`：抖音、小红书、视频号、闲鱼策略
- `07_私域承接话术.md`：进粉后客户分层和沟通话术
- `08_员工训练与考核SOP.md`：新人训练和日常考核
- `09_周复盘模板.md`：每周内容数据与员工问题复盘
- `10_PPT汇报素材库.md`：会议汇报、PPT、阶段复盘素材
- `11_完整PPT逐页稿.md`：10 页汇报 PPT 的页面内容和上台讲稿
- `12_PPT短句版.md`：适合直接放进 PPT 页面的精简短句版
- `13_最新7类流量文案与剪辑落地SOP.md`：最新选题结构、封面画面和剪辑执行作业单
- `14_内训PPT课程包索引.md`：6 份内训 PPT 的课程顺序、训练目标和文件索引
- `15_过往思路学习内训汇总.md`：过往思路学习文章提炼成内训 PPT 的课程说明

## 后续更新方式

每次新增资料时，优先判断资料类型：

- 文案：更新选题库、脚本模板库、产品表达词库
- 视频数据：更新周复盘模板和有效选题
- 产品资料：更新产品细节表达词库
- 员工问题：更新员工训练与考核 SOP
- 客户反馈：更新私域承接话术和高客单客户画像
- 汇报需求：更新 PPT 汇报素材库
