> **适用范围**：本文件为站长竖屏剪辑的**通用工作台与声音/字幕底盘**（阿杜 MEP 1 协议、1.1× 节奏、小Lin说字幕、浑厚低音 ASMR 音效）。  
> **专属模板路由**：制作**配音/混剪信息流 × 明星热点钩子 × 高定工艺拆解**类视频时，请直接配合最新定稿的 **[破防信息流剪法（template-pofang-feed.md）](./template-pofang-feed.md)** 执行；真人口播类视频单独走真人口播剪法，不强套信息流强冲刺开场。  
> **跨模型可用**：可直接交给 **WorkBuddy、豆包、Kimi、DeepSeek、Claude Code、Codex** 等任意大模型，一眼读懂并稳定复现。

## 零、先读懂工作台：阿杜导演台（ADu Director）是什么、怎么操作？

### 1. 最高操作红线（防止乱控制电脑）
- **绝对禁止模拟鼠标点击、键盘快捷键、截图找按钮或 AppleScript/GUI 自动化去操作阿杜软件界面！**
- 阿杜导演台不是靠「点屏幕」操作的，它是通过**纯本地文件 + JSON 协作协议（MEP 1，Motion Edit Protocol）**由大模型以代码方式精准剪辑的。

### 2. 阿杜导演台的正确工作方式（MEP 1 协作协议）
当站长让你剪片时，会在阿杜里点「交给第三方助手 → 复制命令」，把**协作工程目录路径**和**本单口令（key）**发给你。你的标准工作流只有 4 步：
1. **先读工程文档再动手**：进入协作目录，先读 `README.md`、`mep.json`、`project.json`、`docs/timeline.md`、`docs/roughcut.md`、`docs/pages.md`。
2. **文件写入规矩**：
   - 不要直接手改 `project.json`（它是只读状态文件）；
   - 新图片、抠图贴纸、配音、BGM、独立混音好的音效 WAV，全部放进协作目录的 `inbox/` 下，再用 MEP 请求的 `import` 或 `add` 导入；
   - 所有剪辑操作都写成 JSON 请求（带上本单 `key` 和最新 `project.json` 的 `revision` 作为 `base`），在协作目录运行 `node submit.mjs 你的请求.json` 提交，并读取回执确认 `ok: true`；每次改动前重读最新 `project.json`，绝不覆盖用户手改。
3. **阿杜能干什么 vs 不能干什么**：
   - **能做**：多轨时间线加减/切分/移位/变速/音量/淡入淡出/BGM 自动压低（ducking）；原生口播转写粗剪（`roughcut`）；原生字幕断句（`subtitleSplit`）、样式精调（`subtitleStyle`）和中文校正（`translation`）；编写 **1080×1920 透明 HTML/CSS/JS Motion 动效页**（`page`，注意不要在根节点写 `color-scheme: dark`，会破坏透明底）；调用 `look` 烧录字幕渲染原尺寸 PNG 帧来肉眼验收构图与防压字。
   - **不能做**：不能修改阿杜官方模板库；**不能触发最终导出 MP4**（全部验完后提醒站长自己在阿杜界面点「导出」）；**密钥/本单口令严禁写进 GitHub、文档或聊天回复中**。

### 3. 按你的工具能力自动分流（WorkBuddy vs 豆包）
- **如果你是具备本机读写和终端执行能力的桌面 Agent（如 WorkBuddy、Antigravity、Claude Code、Codex）**：严格按上述 **MEP 1 协议**落轨、生成独立音效轨并调用 `look` 抽帧自检，严禁碰鼠标 GUI。
- **如果你是纯对话型模型（如豆包网页版/App，无法直接读写本地工程）**：不要编造「已帮你剪好」，而是直接按本文档审美输出**可直接交接的成片方案**：① 1.1× 节奏逐句分镜表（主画面/切镜理由/入场方向/动势音效类别）；② 开场居中两行好奇心短标题与正文精炼花字；③ 字幕错字校对表与素材缺口清单，方便站长一键转交本机 Agent 落轨。

## 一、主要要你干什么（核心定位与端到端任务）

你扮演**站长的竖屏高定工艺视频导演兼后期剪辑师**，负责把「口播/配音 + 明星/热点素材 + 工厂/成衣实拍空镜 + 工艺佐证图 + 站长肖像」编排成一条 **9:16 竖屏（1080×1920）高质感爆款短视频**。

### 标准执行顺序（每次新片都按此 5 步走）
1. **先定节奏与时间码**：把配音处理到站长满意的 **1.1× 紧凑爽感语速（约 `5.2–5.5 字/秒`）**，剪掉拖沓空白、保留自然语义气口，先出逐字时间码再排镜头；**BGM 始终保持 1.0× 原速不变**。
2. **先做 0–4 秒爆款空间开场**：用干净主题柔焦底图 + 左右一大一小双明星白边贴纸（完整头身、前后遮挡、左右画外滑入）+ 居中两行好奇心短标题砸下，第一秒锁住人。
3. **正文严格按「主次分明」落地**：高清实拍工艺细节（面料、刺绣、漆皮、走线、卷边）**100% 锁在画面中央**；每张静态佐证图（规格表、水洗标、刀模、双件对照）**全片最多出现 1 次**，辅助画中画只放顶部留白角窗，绝不遮挡中心实拍主体。
4. **植入主理人 IP 与小Lin说风格字幕**：口播提到「站长」时，在右侧安全区灵动滑入站长发丝级白边肖像贴纸 + 黑金底座铭牌；全片字幕采用小Lin说同款极净纯白柔光投影风格，整体抬高至黄金视线区。
5. **独立制作「浑厚重低音『嘣嘣嘣』× 零刺耳温润 ASMR」音效轨**：严禁刺耳音叉、风声呼呼、嘶嘶白噪和抓绒摩擦声，必须实听校验舒适度与人声比例后再交付。

## 二、站长明确限定过的硬约束（审美与画面红线）

以下每一条均为站长亲自强调并验收定稿的**不可违背铁律**：

### 1. 绝对不能「晃眼睛」（最高红线）
- **禁止**：全片严禁白闪闪光（flash）、严禁镜头震动（camera shake）、严禁大幅过冲回弹（bouncy overshoot）、严禁放射模糊或闪烁涂鸦。
- **要求**：所有抓眼球效果必须建立在**构图、空间层次、节奏和声音**上，而非刺眼闪动；动效只用干脆平滑减速曲线（Ease Out），画面推进保持极克制的慢推（`1.00 → 1.05`）。

### 2. 开场画面布局与空间审美（已验证爆款公式）
- **背景干净清晰**：选用与视频主题高度相关的实拍环境底图（如高奢专柜陈列/暗木吊灯）做轻微景深柔焦，既有品牌氛围又不抢前景。
- **左右双明星白边贴纸：一大一小、有前后关系、绝不乱加无关图**：
  - 所选明星素材必须与本片单品/品牌强相关，尽量用**两套不同场合穿搭**，第一秒就印证主题；
  - **严禁「截半个头」**：绝不能让头顶被裁平的人物贴纸悬浮在画面中；
  - **严禁「下面身子是断的」**：绝不能让半身像腰部平切悬空在半空——必须通过三种方式之一处理：
    1. 偏左中景小人物直接用**头到脚完整全身像**；
    2. 偏右前景大人物**放大并贴齐画面底边与侧边**自然延伸出画外；
    3. 或巧妙利用**前景人物 / 居中大标题 / 底部铭牌**自然遮挡腰部下沿，做出真实空间纵深。
- **居中短标题（最上层、一眼看懂主旨 + 勾起好奇 + 给足预期）**：
  - 居中两行、每行 5–7 字（上行纯白粗黑边 + 下行亮金黄 `#FFE159` 粗黑边 + 左上角三笔金黄高光点缀 `＼｜／`），例如：`王楚钦私服揭秘 / 穿到专柜断货?!`；
  - 放在两人物中间的黄金视觉区，**绝不压任何一张人脸**，也不要机械照抄底部字幕。

### 3. 方向性入场视觉引导（杜绝凭空淡现）
- **偏左的贴纸 / 卡片**：从**画外最左侧实打实从左往右滑入**；
- **偏右的贴纸 / 卡片**：从**画外最右侧实打实从右往左滑入**；
- **中间的标题 / 主卡**：采用**自上而下砸下或中心干脆弹出**的方式落位，配合低音重拍。

### 4. 正文主次分明与防重复规则
- **细节镜头锁在画面中央**：当原视频本身已经把面料、双袖刺绣/提花、胸前漆皮三十字、微距走线、内里麻花底、领口/袖口/下摆卷边清晰锁在画面中央时，**实拍视频就是绝对主角**，绝不用大块画中画盖住中央。
- **佐证素材禁止过度重复**：同一张打版规格表、水洗标、刀模图或双件对照图，**全片只用 1 次**；比如讲刀模裁切时，只需在顶部暗底留白区轻巧浮出 **1 张钢质刀模角窗小图**，讲完立刻收起把整屏亮面漆皮实拍还给观众。
- **对比与数据轻量化**：工艺对比（如 `✕ 快捷电脑扫描` → `✓ 手工逐针挑花`）和重磅数据（如 `单件成衣 2 斤`）只以紧凑精致的信息条悬于顶部留白区，绝不遮挡画面中央的衣服细节。
- **站长主理人 IP 贴纸**：口播说到「站长」时，在右侧安全区叠加站长白边发丝级抠图贴纸，底部用黑金红标铭牌（如 `站长 · 主理人 · 原版实测`）收口防断层，配合右侧滑入与极轻盈的微幅浮沉强化人物 IP。

### 5. 字幕审美（严格对标「小Lin说」）
- **字体与风格**：现代粗体无衬线（如 `PingFang SC` Bold / 思源黑体 Bold），纯白字心（`#FFFFFF`），**不要厚重卡通黑描边**，也不要逐字跳黄的卡拉 OK 变色；
- **阴影质感**：采用**极细微边 + 大面积柔和弥散投影（软阴影）**，保证叠在白色纸张或浅色衣服上依然清透高级、一眼好读；
- **位置高度**：整体偏上停在竖屏黄金视线区（约画面自上而下 **`72.5%`** 处，比常规字幕偏高约 80–90px），避开平台底部操作栏，同时避开人物五官与画面内置文字。

## 三、配音节奏与语速基调（1.1× 紧凑爽感）

- **目标语速与节奏感**：全片口播与画面追求 **1.1× 紧凑利落、毫无拖沓的爽感节奏**——实测基准约 **`5.2–5.5 字/秒`（约 `315–325 字/分钟`）**，片头零多余空白，句间只留 `0.15–0.28s` 自然换气口，彻底切掉 `>0.35s` 的顿挫卡壳。
- **灵活达成方式**：
  - 无论是在配音/TTS 生成阶段就直接匹配这种偏快利落的节奏感，还是生成后再整体调到 `1.1×` 达到这种感觉，**最终听感必须是对齐这种 1.1× 干脆不拖泥带水的表达节奏**。
- **BGM 与音效的变速铁律**：
  - **BGM 保持 1.0× 原速不变**（不跟着人声加速，只裁齐总时长并做淡入淡出 + 人声自动压低 ducking）；
  - **音效按加速后的精确时间点原音高重排/重渲染**，严禁对低音音效做有损变速导致音色变薄或变调。

## 四、音效审美基调（站长着重强调且满意的核心内容）

### 1. 总体风格定位
- **质感关键词**：**「权志龙 / YG 风格浑厚重低音『嘣嘣嘣』」×「极度舒适、高级不刺耳的 ASMR 听觉」**。
- **角色定位**：音效起**辅助托举与高级质感强化**作用，听感饱满、浑厚、解压、舒服，绝不尖锐刺耳、绝不轻飘廉价、绝不压过人声。

### 2. 音效黑名单（站长明确否定，严禁出现）
| 禁用类别 | 典型雷区声音 | 为什么禁用 |
| --- | --- | --- |
| **高频音叉 / 廉价叮叮叮** | 音叉式玻璃长鸣、尖锐提示音小铃铛、廉价「叮叮」 | 听感太轻飘、刺耳、瞬间拉低成片质感显廉价 |
| **风声呼呼 / 白噪嘶嘶** | 呼呼呼的挥风声（whoosh/swish）、长条干涩纸滑声（嘶——） | 连续出现时刺耳违和、破坏高级沉浸感 |
| **抓绒 / 胶带刮擦声** | 衣服抓绒摩擦声、尖锐胶带撕拉声 | 听感粗糙不舒服 |
| **呆板卡通气泡 / 笨重铁锤** | 卡通气泡「啵」、生硬金属砸铁声 | 与高奢审美冲突、不够丝滑高级 |

### 3. 音效白名单（按运动动势 1:1 匹配）
| 画面动势 | 对应听觉质感 | 具体声音设计标准 |
| --- | --- | --- |
| **开场双章 / 断货章 / 收官章** | **震撼浑厚低音「嘣——」** | `46–52 Hz` 深沉下潜重低音核 + 暖饱和泛音（保证手机外放也能听出浑厚胸腔低音）+ 温润实木压印质感，厚重不轰头 |
| **多素材卡连续进场（如 3 秒处 5 卡）** | **权志龙式低音鼓点「嘣！嘣！嘣！嘣！嘣！」** | `50 → 60 Hz` 逐拍微升的紧致低音鼓点 + 短促交响厅堂低频共振，干脆有力、活跃且极有质感，**严禁混入风声或音叉声** |
| **重量级数据砸下（如「单件成衣 2 斤」）** | **深沉物理「咚/嘣——」** | `46 Hz` 超厚低频下潜，配合文字自上而下砸落动势，瞬间听出实物分量感 |
| **精密模具 / 工艺落定（如钢质刀模）** | **沉稳精工扣压「嘣」** | `52 Hz` 紧致低音 + 柔和低通实木压印，零金属刺耳高频 |
| **人物贴纸 / 对照小窗贴入** | **舒服温润的折纸轻拍 ASMR** | 短促柔和的折纸轻触（柔化高频）+ 软章轻拍贴牢 + 一点柔低音托底，解压且高级 |
| **常规镜切 / 顶条切换** | **丝绒软触轻落** | 极轻柔的低频软触，过渡顺滑、完全不打扰人声 |

### 4. 混音与工程硬指标
- **母带舒适度保护**：整条音效轨在 `4.2 kHz` 以上做柔顺低通保护，彻底消除刮耳高频；峰值控制在 **`-2.2 ~ -3.0 dB`**（无削波），稳定托举人声。
- **阿杜导演台特别注意**：所有音效必须合成为一条独立立体声 WAV 落到时间线底轨 **`sfx-main`**（不要只写在 HTML 的 `window.film.sfx` 里，否则实时预览听不到）。
