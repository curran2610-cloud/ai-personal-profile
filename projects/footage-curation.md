# 高质素材筛选与建库规范（Footage Curation & 5-Gate Standard）

> **方法论来源**：融合 GitHub 开源视频选材与质检项目 `Melvynx/video-agent-skills`（本地素材库抽帧索引）、`EditAtlas/skills`（多维度镜头质量打分）、`louisedesadeleer/b-roll-finder`（逐字稿实体强绑定）与 `GVCLab/CutClaw`（`shot_plan` 内部切点扫描），并严格对齐站长珠宝/高定工艺实拍矩阵。

---

## 一、选材 5 道硬闸门（落轨前必须全过）

### 1. 实体 100% 强一致（Entity Lock，绝不张冠李戴）
- **禁止只看文件名或文件夹名盲配**：落轨前必须通过抽帧或预览核验画面真实主体（具体款型、材质、工艺环节、背景色）。
- **示例**：口播说「925 素银双十字」绝不配镶钻/绿松石款；口播说「布轮抛光」绝不配敲打/焊接镜头；口播说「侧面手工刻字」优先匹配真实钢针凿刻或黑底侧面刻字微距。
- **本地索引建议**：对高频复用的实拍库（如 `站长产品实拍/`、`工厂素材/`），按 `款型 / 材质 / 工序 / 背景色调 / 是否有自带字` 维护视觉清单，做到秒级精准调用。

### 2. 单一连贯镜头（Zero Flash-Cut，0 内部闪切）
- **落轨前必扫内部硬切点**：选定某段素材的 `[in, out]` 截取区间前，必须用 `ffmpeg` 场景跳变检测（`select='gt(scene,0.28)'`）或逐帧抽检确认该区间内**没有原片自带的内部跳切**。
- **杜绝 `< 1.2s` 晃眼闪切**：若原片内部有镜头切换（例如前段秤重、后段游标卡尺），必须把入点明确移到切点之后 `0.5s` 以上，保证每段空镜都是完整连贯的单一运镜。

### 3. 自带标记审查与字幕带洁净度（Clean Frame × Safe-Zone）
- **纯工艺/微距空镜**：优先选用**零自带花字、零水印**的干净实拍全屏铺底，文字与重点统一交由动效层按当前脚本生成，最大化矩阵复用率。
- **自带必要对比标记的素材**（如 `cus vs 正品`、`一眼 / 通货 / 站长`）：
  - 先判断是否对论点必要——必要则保留，不必要则换无字版本；
  - **严禁把底部带字的素材直接全屏铺底**（会与成片底部 70%–85% 字幕带正撞）；必须装进屏幕中上部的居中/微倾卡片里呈现，确保自带标记与成片字幕彻底分离。

### 4. 画质、底色与画幅硬指标（Sharpness & Aesthetic Fit）
- **高级感底色优先**：优先挑选**纯黑底、深灰绒布、暗胡桃木、冷静金属台面**等低饱和高质感实拍，天然融入清醒黑白灰 `90-8-2` 调色体系。
- **清晰度与画幅**：优先原生 `9:16` 竖屏、主体对焦锐利、无过曝死白、运镜稳定；避免强行拿横屏硬裁导致主体被切或画质发虚。

### 5. 信息依次释放 × 单品递进强调（Sequential Release & Progressive Emphasis）
- **信息必须依次释放，严禁提前剧透**：证据截图、核心对比、爆点实锤必须严格跟随叙事节奏**分步、逐层释放**（钩子 → 痛点 → 实锤 → 工艺拆解 → 单品微距 → 终极对比），绝不能在开头就把后半段的核心实锤截图提前塞进去消耗掉。
- **允许为强调核心单品做「视角/景别递进式」复用**：要打透某一款主推单品（如银双十字），同一产品完全可以通过**全景/整盘 → 局部放大 → 旋转/换角度特写 → 保留空间留白做标注对比**反复出现，让观众越看越清晰。
- **严禁无信息增量的“原地平铺重复”**：禁止把同一张未作景别/视角变化的截图或同一段一模一样的空镜，在片中原封不动重复放两遍。

## 二、快速质检命令参考（防内部闪切）

```bash
# 扫描单条实拍视频的内部硬切点（输出 pts_time）
ffmpeg -i "素材路径.MOV" -vf "select='gt(scene,0.28)',showinfo" -f null - 2>&1 \
  | grep "pts_time" | awk '{for(i=1;i<=NF;i++) if($i~/^pts_time:/) print $i}'
```
