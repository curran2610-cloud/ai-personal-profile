# 出口转内销 · 外网搬运风模板（v1.0.0）

> **模板定位**：适用于站长**「外网造势 → 转回内销」**的降维打击打法——先按纯正欧美高奢潮牌纪录片（Highsnobiety / Hypebeast / Vox / Reels）标准制作全英文原生大片，再在动态英文字幕正上方叠一层「海外搬运翻译组」风格的中文译文轨，回流国内抖音/小红书平台，极大抬升专业权威感与完播率。
> **核心原则（灵活不死板）**：本模板**不锁死固定开场公式**，一切构图与镜头节奏优先从本篇最强原生素材出发，严格服从 [剪辑总纲](master-principles.md) 的底层审美（清醒黑白灰 `90-8-2`、顶栏弹性隐现、2.5D 单焦点聚光划重点、5 道选材硬闸门、0 内部闪切）。

## 一、剧本与配音规范（原生欧美奢潮语感）

1. **地道英文改写（拒绝机翻）**：
   - 切碎长句，改用外网 Chrome Hearts / 奢潮圈高频原生短语（如 `1-of-1 custom denim`、`embossed waist patch`、`legit-check chaos`、`thermal receipt`、`grocery store slip`、`authentic vintage Levi's 501 base`、`imported full-grain leather`、`solid 925 sterling silver`、`indistinguishable from retail`）；
   - **货币与量级外网化**：人民币价格按汇率自然转换为美元（如「公价百万」→ `$200,000` / `six-figure denim`），数字在字幕里一律用短写（`$200,000`）防止长单词折行。
2. **按情绪选音色（不固定单一声线）**：
   - 默认推荐磁性沉稳的外网纪录片男声（如本地豆包 Seed-TTS 2.0 `zh_male_m191_uranus_bigtts` 云舟 2.0 英语模式，0 积分消耗），也可按选题气质灵活选用其他原生多语种声线；
   - 按三幕情绪（开场悬念钩子 → 中段冷峻揭秘 → 后段工匠底气）分段带 `--context` 情绪指令生成并无缝拼接。

## 二、外网搬运风双语字幕规范（辨识度核心）

采用**「上：搬运翻译中文轨 / 下：原版动态词级英文」**的经典海外搬运号视觉层级，统一在顶层 HTML Motion 内精确渲染（关闭阿杜原生字幕防重影，导出 MP4 直接自带烧录双语字幕）：

1. **上方中文翻译轨（`#sub-zh`）**：
   - 半透黑曜石底条（`rgba(10, 11, 15, 0.78)` + `1px solid rgba(255,255,255,0.16)`）+ 圆润轻量中文字体（`AlimamaFangYuanTi-VF.ttf`，`46px` 纯白粗体）；
   - 与下方每一组英文词段严格同步，意译地道干脆、绝不出现漏译或机翻腔。
2. **下方原版动态词级英文字幕（`#sub-text`）**：
   - 按 `3–5` 词/组自然断行，超粗现代无衬线大写（`Arial Black / Helvetica Neue`，`44px` + `8px` 深黑描边）；
   - 当前朗读单词实时高亮亮金 `#FFE159` 并微幅弹出（`scale(1.08)`），营造纯正 TikTok / Reels 完播节奏。

## 三、画面重构与外网化包装

1. **开场按素材原创（告别固定贴纸套路）**：
   - 优先选用本篇最高清的原生 4K 实拍做**「大字穿人 × 杂志封面活过来」**三层景深开场（底层原画 → 中层 `CHROME HEARTS · EXCLUSIVE` 眉标与巨型穿人英文大字 → 前景 Vision 1:1 无白边原画人物），开场结束瞬间一镜到底无缝接棒动态实拍；
   - 也可按具体选题素材气质自由创作其他杂志封面 / 纪录片片头，唯一不变的是**第 1 帧立刻锁死眼球**。
2. **证据卡片外网化 × 2.5D 单焦点聚光**：
   - **杜绝把密密麻麻的中文长文截图堆在一屏**：涉及行情报告、鉴定乱象、买家实测等证据时，重构为纯英文高定杂志风 2.5D 透视卡片（如 *MARKET REPORT* / *AUTHENTICATION CRISIS* / *VERIFIED COLLECTOR FEEDBACK*），一次只聚焦 1 个大字主角，锁稳后划暖黄/朱红荧光笔；前卡压暗退居左后景拉出真实景深；

## 四、节奏、倍速与混音铁律（防炸音、零错位）

1. **整体 `1.1×` 爽感节奏**：
   - 英文口播在时间线设为 `speed: 1.1`；
   - 顶层 HTML Motion 页面在 `window.film.frame(t)` 内精确映射 `st = t * 1.1`（片段 `time` 设为 `[0, 原时长 / 1.1]`）；
   - 全部 Track-1 空镜起止时间 `at` 按 `/ 1.1` 同步前移并匹配速率，保证 0 缝隙、0 重叠。
2. **BGM 原速不炸音**：
   - BGM 始终保持 **`1.0×` 原速**（不跟口播变速变调），按最终成片总时长精确裁切、第 1 帧强鼓点 Drop 对齐 `0.000s`、尾部 `1.2s` 淡出；
   - 混音推荐基准：高燃 140 BPM Trap BGM 设为 `volume: 0.38` + 人声闪避 `duck: {"under":["voice"],"speech":-11,"pause":-5}`，英文口播 `volume: 1.45`，确保人声通透响亮、绝不被 BGM 盖住。
3. **音效毫秒级重算铁律**：
   - **任何时候只要修改了动效分幕时间点、转场或整体倍速，必须同步按最新时间点重新渲染 `4.2 kHz` 丝绒低通独立音效轨（`render_asmr_bass_sfx.py`）并替换上轨**，严禁残留错位空响。
